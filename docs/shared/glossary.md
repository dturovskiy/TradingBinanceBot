# Glossary

- `BinaceBot`: private runtime repository with executable code.
- `TradingBinanceBot`: public documentation repository.
- `TradingExecutor`: orchestrator of per-iteration trade flow.
- `RiskManager`: portfolio risk policy evaluator.
- `Feature Flag`: runtime rollout switch in config.
- `Circuit Breaker`: guard that blocks symbols after repeated failures.
- `Illiquid Position`: symbol temporarily blocked from trading.
- `Dry-run`: simulation mode without real order placement.
- `Testnet`: Binance testing environment.
- `Mainnet`: live Binance environment with real funds.
