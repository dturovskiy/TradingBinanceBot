# Documentation Scope

## Purpose

`TradingBinanceBot` is the public documentation repository for the private `BinaceBot` runtime.

## In Scope

- User and operator documentation.
- Architecture overviews.
- Testing and validation workflows.
- Logging and monitoring guides.
- Cross-repo integration references.

## Out of Scope

- Private runtime source code.
- API secrets and environment credentials.
- Production runtime data.
- Internal-only operational artifacts.

## Repository Boundary

- Public docs repository: `TradingBinanceBot`.
- Private implementation repository: `BinaceBot`.
